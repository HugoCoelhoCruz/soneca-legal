Política de Privacidade

Soneca — Alarme por Proximidade

📅 Última atualização: Setembro de 2026

✅ O Soneca não coleta, armazena ou compartilha seus dados pessoais em servidores externos. Todos os dados ficam exclusivamente no seu dispositivo.

1. Introdução

O Soneca é um aplicativo de alarme por proximidade desenvolvido para ajudar usuários a não passar do destino durante viagens de transporte público ou privado.

Esta Política de Privacidade descreve como coletamos, usamos e protegemos as informações no contexto do aplicativo, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2. Dados coletados e utilizados

O Soneca coleta e utiliza os seguintes dados:

  • Localização GPS: usada exclusivamente para detectar a proximidade do destino marcado e disparar o alarme. Não é enviada para nenhum servidor externo.
  • Destinos e favoritos: armazenados localmente no dispositivo para uso do histórico e favoritos.
  • Dados de uso (AdMob): coletados pelo Google AdMob para exibição de anúncios na versão gratuita, conforme política do Google.

3. Armazenamento de dados

Todos os dados do aplicativo — destinos, favoritos, histórico e configurações — são armazenados exclusivamente no dispositivo do usuário utilizando armazenamento local (AsyncStorage).

Nenhum dado pessoal é enviado ou armazenado em servidores externos.

4. Localização em segundo plano Importante

O Soneca solicita permissão de acesso à localização em segundo plano para funcionar corretamente com a tela bloqueada, que é o principal caso de uso do aplicativo.

Esta funcionalidade é essencial para o propósito do app: alertar o usuário quando se aproximar do destino mesmo com o celular na bolsa ou com a tela desligada.

A localização é utilizada somente durante o monitoramento ativo e nunca em segundo plano sem o consentimento e ativação explícita pelo usuário.

5. Publicidade — Google AdMob

A versão gratuita do Soneca exibe anúncios fornecidos pelo Google AdMob. O Google pode coletar dados para personalização de anúncios conforme sua própria Política de Privacidade.

Ao abrir o aplicativo pela primeira vez, será exibido um formulário de consentimento para uso de dados em anúncios, conforme exigido pela legislação aplicável.

Usuários da versão Soneca Pro não são expostos a anúncios e, portanto, não têm dados coletados pelo AdMob.

6. Compras in-app

O Soneca oferece a versão Pro mediante compra in-app gerenciada pelo RevenueCat em conjunto com as lojas oficiais (Google Play Store e Apple App Store).

Não armazenamos dados de pagamento. Todas as transações são processadas diretamente pelas lojas oficiais.

7. Seus direitos — LGPD

Conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Acessar seus dados armazenados localmente
  • Corrigir dados incompletos ou incorretos
  • Solicitar a exclusão dos seus dados
  • Revogar o consentimento de anúncios
  • Obter informações sobre o uso dos seus dados

Como todos os dados são armazenados localmente, você pode exercer esses direitos diretamente nas Configurações do app → Limpar dados. Para revogar o consentimento de anúncios, acesse Configurações → Consentimento de anúncios.

8. Compartilhamento de dados

O Soneca não vende, troca ou compartilha seus dados pessoais com terceiros, exceto:

  • Google AdMob (somente na versão gratuita, para exibição de anúncios)
  • RevenueCat (para gerenciamento de assinaturas e compras)
  • Lojas oficiais (Google Play / App Store) para processamento de pagamentos

9. Segurança

Adotamos medidas técnicas para proteger os dados armazenados localmente no seu dispositivo. Recomendamos que você mantenha seu dispositivo protegido com senha ou biometria.

10. Crianças

O Soneca não é direcionado a crianças menores de 13 anos e não coleta intencionalmente dados de crianças. Se você acredita que uma criança forneceu dados ao aplicativo, entre em contato conosco para remoção.

11. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. Alterações significativas serão comunicadas através do próprio aplicativo. O uso continuado após as alterações implica aceitação da nova política.
